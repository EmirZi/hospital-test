# Онлайн-тестирование больницы

Статический сайт на HTML, CSS и JavaScript. Работает локально при открытии `index.html` и на GitHub Pages. Сервер, Node.js, npm и база данных не нужны.

## Публикация на GitHub Pages
1. Загрузите в репозиторий все файлы из папки проекта, сохранив их расположение.
2. Откройте **Settings → Pages**.
3. Выберите публикацию из нужной ветки и папки (`/(root)` или `/docs`, в зависимости от расположения файлов).
4. Откройте выданный GitHub Pages URL.

## Как добавлять тесты и вопросы
Все тесты редактируются в `questions.js` в массиве `window.TESTS`. Не редактируйте `script.js`, `index.html` или `style.css` для обычного добавления вопросов.

Каждый тест должен иметь уникальный `id`, состоящий из латинских букв, цифр и дефисов. Например:
```js
{
  id: "surgery",
  title: "Тест по хирургии",
  description: "Проверка знаний сотрудников",
  timeLimit: 15,
  passPercent: 80,
  shuffleQuestions: true,
  shuffleAnswers: true,
  theme: "surgery",
  questions: [
    {
      id: "surgery_001",
      question: "Пример вопроса?",
      type: "single",
      answers: ["Вариант А", "Вариант Б", "Вариант В"],
      correct: [1],
      points: 1
    }
  ]
}
```
Добавьте новый объект через запятую после предыдущего объекта в `window.TESTS`. Внутри `questions` можно добавить любое количество вопросов.

### Поля теста
- `id` — уникальный ID теста, он же используется в ссылке `?test=ID`.
- `title`, `description` — название и описание.
- `timeLimit` — минуты; `0` отключает таймер.
- `passPercent` — проходной процент от 0 до 100.
- `shuffleQuestions`, `shuffleAnswers` — включить (`true`) или отключить (`false`) перемешивание.
- `theme` — `surgery`, `vaccination`, `admin`, `emergency`, `training`, `dark` или `default`.

### Поля вопроса
- `id` — уникальный ID вопроса в пределах теста.
- `question` — текст.
- `type` — `single` для одного ответа или `multiple` для нескольких.
- `answers` — массив вариантов ответа.
- `correct` — индексы правильных ответов, нумерация начинается с `0`. Например, второй ответ — `[1]`, первый и третий — `[0, 2]`.
- `points` — максимальный балл за вопрос; если не указан, используется `1`. Должен быть конечным числом больше нуля.

### Множественный выбор
```js
{
  id: "surgery_002",
  question: "Выберите все правильные варианты",
  type: "multiple",
  answers: ["Первый", "Второй", "Третий", "Четвёртый"],
  correct: [0, 2],
  points: 2
}
```
Баллы начисляются только за точное совпадение выбранных вариантов с `correct`: если пропущен правильный вариант или выбран лишний, баллы за вопрос равны нулю.

### Ссылки на отдельные тесты
После публикации используйте:
- каталог: `https://ВАШ-АККАУНТ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`
- отдельный тест: `https://ВАШ-АККАУНТ.github.io/ИМЯ-РЕПОЗИТОРИЯ/?test=surgery`
- вакцинация: `...?test=certification`

Замените примерный адрес на URL своего сайта. Новый тест автоматически получает ссылку по его `id`. Кнопка «Поделиться тестом» копирует ссылку. Неизвестный ID показывает сообщение «Тест не найден».

## Подсчёт результатов
За каждый вопрос начисляется либо все его `points`, либо 0. Процент рассчитывается без промежуточного округления: `полученные баллы / максимальные баллы × 100`. Округление применяется только к отображению. Проходной порог сравнивается с фактическим процентом. Пропущенные ответы дают 0 баллов.

## Проверка ошибок
При загрузке сайта проверяется структура тестов. Ошибки отображаются в консоли браузера (F12 → Console) с названием теста и номером/ID вопроса. Исправьте ошибки в `questions.js`, затем обновите страницу.

## Важное ограничение безопасности
GitHub Pages публикует JavaScript-файлы. Правильные ответы в `questions.js` доступны посетителям, которые умеют просматривать исходный код. URL-параметр не защищает ответы. Для защищённых экзаменов нужна серверная проверка и авторизация.
